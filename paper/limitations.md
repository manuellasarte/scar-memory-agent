# Limitations

# English

The following limitations are acknowledged explicitly:

1. Synthetic error streams.
2. Single random seed (42).
3. Declared utility model, not empirically measured.
4. Single-agent evaluation only.
5. Fixed scar formation threshold (0.55).

Each corresponds to a concrete direction of future work. None
invalidates the core claim of the paper.

---

# Español

Se reconocen explícitamente las siguientes limitaciones:

1. Flujos de error sintéticos.
2. Semilla aleatoria única (42).
3. Modelo de utilidad declarado, no medido empíricamente.
4. Evaluación mono-agente únicamente.
5. Umbral de formación de cicatrices fijo (0.55).

Cada una corresponde a una dirección concreta de trabajo futuro.
Ninguna invalida la afirmación central del paper.
