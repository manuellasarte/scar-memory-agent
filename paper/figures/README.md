# Paper Figures

# English

## Purpose

Figure sources for the paper.

## Files

- `pipeline.mmd` — Mermaid diagram of the full system pipeline.
- `pipeline.txt` — ASCII fallback, useful for plain text contexts.

## How to render

- Mermaid: paste `pipeline.mmd` into https://mermaid.live or any
  Mermaid-compatible Markdown viewer.
- Export as SVG or PDF and include in the paper as Figure 1.

## What the diagram shows

1. The transformation chain: error → wound → pressure → scar → capability.
2. The evolutionary lifecycle of capabilities: NACIENTE → ACTIVA → CONSOLIDADA.
3. The audit trail stored in SQLite for reproducibility.
