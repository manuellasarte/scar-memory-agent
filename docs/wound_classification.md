# Wound Classification Model

# English

## Principle

A wound must be represented at two levels:

### Surface Level

The exact error observed.

Examples:

- ModuleNotFoundError: requests
- ModuleNotFoundError: pandas
- ModuleNotFoundError: numpy

### Conceptual Level

The underlying failure category.

Examples:

- DEPENDENCY_RESOLUTION_FAILURE
- FILE_ACCESS_FAILURE
- DATA_FORMAT_FAILURE
- TEST_ASSERTION_FAILURE
- API_AUTHENTICATION_FAILURE

---

## Scar Formation Rule

Scars are formed from recurring conceptual failures, not from identical error messages.

---

# Español

## Principio

Una herida debe representarse en dos niveles.

### Nivel Superficial

El error exacto observado.

Ejemplos:

- ModuleNotFoundError: requests
- ModuleNotFoundError: pandas
- ModuleNotFoundError: numpy

### Nivel Conceptual

La categoría subyacente del fallo.

Ejemplos:

- DEPENDENCY_RESOLUTION_FAILURE
- FILE_ACCESS_FAILURE
- DATA_FORMAT_FAILURE
- TEST_ASSERTION_FAILURE
- API_AUTHENTICATION_FAILURE

---

## Regla de Formación de Cicatriz

Las cicatrices se forman a partir de fallos conceptuales recurrentes, no a partir de mensajes idénticos de error.
