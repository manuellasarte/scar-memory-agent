# Emergent Capability Model

# English

## Definition

An Emergent Capability is a reusable behavioural competence that did not exist in the agent's original repertoire and that arises from one or more scars.

A capability is not an error fix.

A capability is a generalized strategy for avoiding or mitigating future failures.

---

## Properties

An emergent capability must be:

- Reusable
- Generalizable
- Observable
- Measurable

---

## Research Hypothesis

Agents capable of developing emergent capabilities from scars will outperform agents relying solely on episodic memory.

---

# Español

## Definición

Una Capacidad Emergente es una competencia conductual reutilizable que no existía en el repertorio original del agente y que surge a partir de una o varias cicatrices.

Una capacidad no es una corrección de error.

Una capacidad es una estrategia generalizada para evitar o mitigar futuros errores.

---

## Propiedades

Una capacidad emergente debe ser:

- Reutilizable
- Generalizable
- Observable
- Medible

---

## Hipótesis de Investigación

Los agentes capaces de desarrollar capacidades emergentes a partir de cicatrices superarán el rendimiento de agentes que dependan únicamente de memoria episódica.
