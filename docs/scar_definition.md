# Scar Memory Evolutionary Agent (SMEA)

# English

## Definition of Failure

A failure is an unsuccessful attempt to solve a task that produces an identifiable error pattern.

Examples:

- ModuleNotFoundError
- FileNotFoundError
- JSONDecodeError
- AssertionError
- API Authentication Error

---

## Definition of Experience

An experience is a recorded interaction containing:

- Context
- Goal
- Action
- Result
- Error (if any)

---

## Definition of Scar

A scar is created when the same failure pattern is observed multiple times and exceeds a persistence threshold.

A scar is not a memory.

A scar is a structural adaptation derived from repeated failure.

---

# Español

## Definición de Error

Un error es un intento fallido de resolver una tarea que produce un patrón de fallo identificable.

Ejemplos:

- ModuleNotFoundError
- FileNotFoundError
- JSONDecodeError
- AssertionError
- Error de autenticación API

---

## Definición de Experiencia

Una experiencia es una interacción registrada que contiene:

- Contexto
- Objetivo
- Acción
- Resultado
- Error (si existe)

---

## Definición de Cicatriz

Una cicatriz se crea cuando el mismo patrón de error aparece múltiples veces y supera un umbral de persistencia.

Una cicatriz no es un recuerdo.

Una cicatriz es una adaptación estructural derivada de fracasos repetidos.
