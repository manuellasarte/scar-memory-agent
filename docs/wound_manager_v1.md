# Wound Manager v1

# English

## Purpose

The Wound Manager is responsible for transforming failures into structured wound records.

A wound is created immediately after a failure is detected.

The system does not wait for recurrence before creating a wound.

---

## Wound Structure

Each wound contains:

- Original Error
- Conceptual Category
- Context
- Severity
- Observation Count
- Current State

---

## Principle

Every failure produces a wound.

Not every wound becomes a scar.

---

# Español

## Propósito

El Wound Manager es responsable de transformar errores en registros estructurados de heridas.

Una herida se crea inmediatamente después de detectar un error.

El sistema no espera recurrencia para crear una herida.

---

## Estructura de una Herida

Cada herida contiene:

- Error Original
- Categoría Conceptual
- Contexto
- Severidad
- Número de Observaciones
- Estado Actual

---

## Principio

Todo error produce una herida.

No toda herida se convierte en una cicatriz.
