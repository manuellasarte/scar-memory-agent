# Capability Registry v1

# English

## Purpose

The Capability Registry tracks the complete lifecycle of emergent capabilities.

Every capability must justify its continued existence through measurable utility.

---

## Capability Attributes

Each capability contains:

- Identifier
- Origin Scar
- Creation Date
- Usage Count
- Success Count
- Failure Count
- Utility Score
- Current State

---

## Principle

Capabilities are subject to evolutionary selection.

Useful capabilities persist.

Useless capabilities may become obsolete.

---

# Español

## Propósito

El Registro de Capacidades rastrea el ciclo de vida completo de las capacidades emergentes.

Cada capacidad debe justificar su existencia continuada mediante utilidad medible.

---

## Atributos de una Capacidad

Cada capacidad contiene:

- Identificador
- Cicatriz de Origen
- Fecha de Creación
- Número de Usos
- Número de Éxitos
- Número de Fallos
- Puntuación de Utilidad
- Estado Actual

---

## Principio

Las capacidades están sujetas a selección evolutiva.

Las capacidades útiles persisten.

Las capacidades inútiles pueden volverse obsoletas.
